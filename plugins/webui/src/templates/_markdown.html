{# Turns what a model wrote into something readable. Everything here builds elements and text nodes. Nothing is ever handed to innerHTML. That is not tidiness: this text comes from a model, a model reads whatever document it was given, and a document can be written by anyone. The moment any of it becomes markup, a translation of somebody's PDF can put a script on the page. It is written here rather than borrowed because these pages fetch nothing — no stylesheet, no script, no font — and the server answers on this machine only. A vendored parser would be the first exception to that, for a job of this size. #}
