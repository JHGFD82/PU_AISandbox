You don't have to work through these. Type in a setting's box and it ticks itself — that's the whole of it. Anything left unticked keeps following whatever the sandbox or the plugin ships, which is usually what you want, so a file with nothing ticked changes nothing for anybody.

It is safe to untick one to see what it was originally: the box goes back to showing the shipped value, and yours is remembered and comes straight back if you tick it on again.

Wording is typed as wording — no quotation marks needed. A list keeps its square brackets, with each item in quotation marks.

Nothing is saved here. The file downloads to you — rename it if you like, put it where your group can read it, and tell each member to enter that path in Settings → Shared settings.
