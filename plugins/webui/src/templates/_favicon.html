{# What the browser puts in the tab. Two of them, because no single file suits every browser. The .ico is the one Safari understands and the one every browser asks for by name whether or not a page mentions it, so it is a real file at a real address — the one thing here that is fetched rather than written into the page. The SVG is the same mark drawn from instructions instead of pixels: Chrome, Firefox and Edge prefer it and stay sharp on a screen of any density, where the .ico has to pick its nearest size and blur. The mark carries a white ground here that the one in the page header does not. In the artwork the tiger is not painted white — it is the page showing through, which works in a header sitting on a panel whose colour we set. A tab bar is not ours to set, and a dark one turned the tiger dark. #}
