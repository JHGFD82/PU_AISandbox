Shared settings & alternate endpoints

A shared settings file lets a group of installations (e.g. everyone you manage) use the same tuned runtime defaults. Alternate-endpoint credentials are the API keys for any non-default AI endpoints defined in settings.default.toml / settings.local.toml.

# settings.local.toml [endpoints.my_cluster] name = "My HPC Cluster" base_url = "http://my-cluster.internal:8000/v1" openai_compatible = true default_model = "llama-3-70b-instruct"

Endpoint definitions (base URL, timeout, etc.) aren't edited from here — add or change them by hand in settings.default.toml or settings.local.toml, following the snippet above, then set the matching credential below. See docs/configuration.md for the full field reference.
